# MotionBox

MotionBox is a project designed to streamline animation and visual workflows, combining modern tools and custom automation.

## 🚀 About the Project
The goal of MotionBox is to provide flexible and efficient tools for creators and animators, simplifying daily workflows in graphic and animation design.

## 🛠️ Key Features & Tools
* Custom scripts and editor utilities to automate workflow tasks.
* Automated rigging system routines for quick node setup (parenting & anchor positioning).

## 👥 Reporting Issues & Suggestions
We welcome feedback and contributions! If you encounter a bug or have a feature idea, please open an issue in the **Issues** tab using our templates:
* **Bug Reports:** Please describe the problem in detail and **include screenshots or screen recordings** showing the issue. Visual context helps us diagnose and fix problems much faster.
* **Feature Requests:** Describe your proposal clearly and explain how it improves the MotionBox workflow.

## 🤝 Contributing & Pull Requests
Want to contribute to MotionBox? Great!
1. Fork the repository.
2. Create a new branch for your feature (`git checkout -b feature/my-new-feature`).
3. Commit your changes (`git commit -m 'Add new feature'`).
4. Push to the branch (`git push origin feature/my-new-feature`).
5. Open a **Pull Request** detailing your changes.
